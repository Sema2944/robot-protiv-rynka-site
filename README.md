# Робот против рынка

Публичный сайт канала [«Робот против рынка»](https://t.me/robot_protiv_rynka): честный журнал демо-торговли торговых роботов.

**Демо-счёт. Не инвестиционная рекомендация.**

Сайт статический: HTML, CSS и JS, без серверной части и без трекеров. Цифры в `data.json` собираются отдельно на рабочей машине и подставляются сюда при обновлении. В этом репозитории нет паролей, токенов и ключей API.
