2. Зачем нужны приложения

Чтобы публиковать ежедневные ролики сразу на несколько площадок, используются служебные приложения владельца:

  • приложение Google Cloud / YouTube с рабочим названием robot-vs-market (YouTube Data API);
  • приложение VK ID Робот против рынка, номер 54908633 (VK API).

Оба приложения нужны только для загрузки видео и сопутствующих данных на собственные каналы и сообщество владельца. Это не сервисы для сторонних пользователей и не площадки, где кто-то регистрируется.

3. Какие данные обрабатываются

Приложения получают доступ только к учётным записям владельца, которые он сам подключает:

  • идентификаторы каналов и сообщества владельца;
  • токены доступа, необходимые для загрузки видео, просмотра статуса своей публикации и управления своими роликами;
  • метаданные загружаемого файла: название, описание, теги, превью, параметры видимости.

Данные других пользователей, зрителей или посетителей сайта не собираются. Мы не запрашиваем и не обрабатываем списки подписчиков, личные сообщения, платёжные данные и контакты аудитории.

4. Google и YouTube API

Для публикации на YouTube используется YouTube Data API. Доступ запрашивается только к функциям, нужным для загрузки и учёта собственных роликов владельца. Информация, полученная через Google APIs, не продаётся, не передаётся третьим лицам для рекламы и не используется, чтобы обучать собственные модели или анализировать чужие аккаунты.

Использование информации, полученной из Google APIs, соответствует Google API Services User Data Policy, включая требования Limited Use.

5. VK API

Для публикации во «ВКонтакте» используется VK API. Доступ нужен только для загрузки видео и размещения записей в собственном сообществе владельца. Данные других пользователей VK через это приложение не запрашиваются и не сохраняются.

6. Как хранятся токены

Токены доступа хранятся защищённо, в ограниченном служебном хранилище, и используются только программами владельца для публикации на его каналах. Токены не передаются третьим лицам, не публикуются и не встраиваются в открытый код сайта.

7. Передача данных третьим лицам

Мы не продаём и не передаём данные, полученные через Google или VK, рекламным сетям, брокерам данных и иным сторонним сервисам. Сами платформы (Google, YouTube, VK) обрабатывают данные по своим правилам, когда владелец входит в свой аккаунт и загружает ролик.

8. Cookies, метрики и трекеры

Этот сайт статический. На нём нет форм сбора данных, счётчиков посещаемости, рекламных пикселей и внешних трекеров. Мы не используем cookie для идентификации посетителей.

9. Как отозвать доступ

Владелец может в любой момент отключить приложения:

  • для Google и YouTube — на странице https://myaccount.google.com/permissions;
  • для VK — в настройках приватности и подключенных приложений аккаунта VK ID / ВКонтакте.

После отзыва доступа новые загрузки через соответствующее приложение прекращаются, пока доступ не будет выдан снова.
